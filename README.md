# Montador 2 x A5 en A4

Herramienta en una sola página para montar dos A5 en un A4 apaisado listo para imprimir.
Todo se procesa en el navegador: las imágenes no se suben a ningún servidor.

## Publicar en Render (Static Site)
1. Crea un repositorio nuevo en GitHub y sube estos tres archivos: index.html, render.yaml y README.md.
2. En render.com: New + > Static Site > conecta el repositorio.
3. Deja el directorio de publicación en blanco o en "/" y pulsa Deploy.
